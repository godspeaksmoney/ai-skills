# Monthly archive intake

The source is the Research tab of [Michael J. Mauboussin’s archive](https://www.michaelmauboussin.com/#writing). The live site merges its embedded archive file with its public writing additions and archive corrections. The baseline contains 183 rows. Distinct editions and revised papers are independently indexed.

1. Compare the current Research list with the manifest using `python scripts/research_intake.py --baseline references/manifest.json` from the skill directory. The inventory comparison uses the Python standard library. If the public feeds or script shape fail, open the rendered tab, verify its count and compare the actual entries. Treat an incomplete fetch as an intake issue. Use the index’s title, year, venue and links to distinguish editions and recognize link corrections.
2. For each addition, changed source and pending review, retrieve the original publication or a verifiable copy. Read all relevant sections and inspect figures or appendices needed to understand the findings, data boundaries and qualifications. Save original paraphrases covering the question, evidence or mechanism, practical use and limitations with one-based PDF pages where verified. Preserve original title, listed date, venue, source and resolved URL, and note differences from the paper’s printed date. Keep failed retrievals pending and record what was accessible. Retain prior review history when an entry disappears or changes.
3. Allocate each new entry the next unused numeric ID. Update the manifest, article notes and index links together. Update the synthesis when the paper adds, extends or qualifies an actionable method. Reference both editions when their evidence differs materially. Record any same-text mirror or duplicated edition separately while reusing shared ideas. A changed URL alone can be reconciled after confirming identity or content.
4. Verify count reconciliation, unique IDs and keys, one note per reviewed entry, working references and any changed synthesis claim. Verify a retrieval about the new paper from the installed skill. On a clean no-change run, avoid file changes and routine notification. Report new papers and material differences, or the exact issue that prevented review or writeback. Never advance review status solely because an entry or title was seen.

`--inventory PATH` can save a current source inventory for reconciliation. Optional `--extract-to PATH` retrieves the PDFs into a temporary directory and needs `pypdf`. Read `--help` for flags. Treat the inventory’s sequential IDs as positions from that snapshot. Preserve existing manifest IDs across runs. Do not publish retrieved full text.
